# Проверка промптов пациентов

Прогоняет пациентов по типам тренировки, считает метрики, даёт отдельной
модели прочитать расшифровки и складывает всё в сводку.

**Инструмент докладывает, а не судит.** Ни порогов, ни кода возврата, ни
«не прошло». Он показывает, что у пациента реплики по сорок секунд при
медиане двенадцать, — а решаем мы. Порогов сейчас взять неоткуда, и
выдуманный красный вердикт быстро научил бы игнорировать инструмент целиком.

## Зачем

Оба самых дорогих дефекта июля-августа нашлись чтением глазами при отличных
числах: немой Станислав (одиннадцать ходов ремарками, боевой оценщик поставил
`paid 9.6`) и монологи Оксаны по сорок секунд (`paid 7.4`). Боевой оценщик их
не видит по устройству — он судит **менеджера**, а ломается **пациент**.

## Где запускать

**Внутри backend-контейнера на DE.** Потолок первого токена — 2 секунды, и
из России он ложно срабатывает на сетевой задержке: половина прогона уйдёт
к резервной модели, и замер превратится в замер канала.

```bash
docker exec ai-trainer-backend-1 sh -c 'cd /app && python -m qa.run --all'
```

Долгий прогон — в фоне, лог остаётся в контейнере:

```bash
docker exec -d ai-trainer-backend-1 sh -c 'cd /app && python -m qa.run --all > /tmp/qa.log 2>&1'
docker exec ai-trainer-backend-1 tail -5 /tmp/qa.log
```

Лог и результаты живут **в контейнере**, а не на хосте: перенаправление
происходит внутри `docker exec`. На этом легко обжечься.

## Рабочий цикл

Главный сценарий — не полный прогон, а точечный перегон починенного.

```bash
# 1. Прогнали всё: 147 клеток, около полутора часов
python -m qa.run --all

# 2. В сводке помечены, скажем, Оксана и Станислав. Правим промпты.

# 3. Гоним ТОЛЬКО их — это минуты, а не полтора часа
python -m qa.run --failed-from qa-runs/2026-08-04T13-28-02

# 4. Смотрим, что изменилось именно у них
python -c "from pathlib import Path; from qa import report; \
  print(report.сравнить(Path('qa-runs/НОВЫЙ'), Path('qa-runs/СТАРЫЙ')))"
```

Сравнение работает и на частичном прогоне: клетки, которых в новом не было,
помечаются «не гонялись», а не «обвалились».

## Аргументы

| | |
|---|---|
| `--all` | вся матрица |
| `--patients` | слаги через запятую |
| `--types` | слаги через запятую |
| `--failed-from ПРОГОН` | только помеченные клетки прошлого прогона |
| `--traps` | только ловушки |
| `--resume ПРОГОН` | доделать прерванный |
| `--repeat N` | повторить каждую клетку N раз |
| `--concurrency N` | одновременных разговоров, по умолчанию 5 |
| `--reader-model` | чем читать, по умолчанию `anthropic/claude-haiku-4.5` |
| `--no-reader` | только механика: быстро и даром |

Без аргументов **ничего не запускается** — печатается, что мог бы прогнать,
во сколько обойдётся и сколько займёт.

## Что считается

Механика, без модели: немые ходы после `strip_for_speech`, ремарки и разметка,
длина реплики в знаках и секундах озвучки, повторы между ходами, латиница
посреди русской речи, обращение к менеджеру собственным именем, сбои
провайдера и задержки первого токена.

Читатель — отдельная модель, судит пациента: держится ли характер, не
повторяется ли, отдаёт ли ход, не подсказывает ли менеджеру. Выдаёт находки
с номером хода и цитатой; **без цитаты находка отбрасывается** — её нельзя
перепроверить.

## Про многословность отдельно

Абсолютного порога у нас нет, поэтому выброс ловится **сравнением с другими
клетками того же прогона**: «втрое длиннее соседей» — факт из данных, а не
выдуманное число.

У этого есть предел, и его надо знать: **если многословны все, выброса нет
ни у кого.** Поэтому в сводке всегда печатается разброс длин по прогону —
на него и надо смотреть, когда поводов не нашлось.

## Результаты

```
qa-runs/2026-08-04T13-28-02/
  run.json          модели, git sha, настройки, замечания к данным
  progress.json     сколько клеток готово — можно смотреть на ходу
  summary.md        таблица клеток и поводы посмотреть
  results/*.json    по клетке: расшифровка, метрики, находки, тайминги, сбои
```

При сбое сохраняется всё: тип исключения, сообщение, номер хода,
предупреждения `services.llm` за этот ход — и готовая команда, чтобы
повторить одну эту клетку.

## Чего он не делает

Не заменяет боевой оценщик (тот судит менеджера), не проверяет голос —
STT и TTS вне охвата, как и у симулятора, — и не блокирует мерж.
