# Инструкции для работы с AI Salesperson Trainer

## Локальный контекст

Если существует [local-materials/AGENTS.local.md](local-materials/AGENTS.local.md),
прочитай его в начале каждого обращения, до работы над задачей. Там находятся
правила общей доски, разделение рабочих папок и ссылки на локальную памятку доступа.
Этот файл исключён из Git; в другой копии репозитория он может отсутствовать.
Не создавай вместо отсутствующего локального хранилища новую доску.

## Общие правила проекта

Прочитай и соблюдай [CLAUDE.md](CLAUDE.md). Это существующая общая памятка
проекта: архитектура, команды, дизайн, проверка изменений и правила продакшена.
Её историческое имя не ограничивает применение конкретным агентом.
Правила не дублируются здесь, чтобы две версии не расходились.

## Платные проверки

Инструкция проверки промптов находится в
[.agents/skills/qa-run/SKILL.md](.agents/skills/qa-run/SKILL.md).
Применяй её только по прямой просьбе пользователя о прогоне; наличие инструкции
не разрешает запуск платных вызовов.
